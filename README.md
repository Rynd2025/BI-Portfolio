## 📌 Présentation du Projet
Ce projet académique démontre la mise en place d'un pipeline BI complet, de l'extraction de données non structurées (NoSQL) à la visualisation stratégique pour la prise de décision.

## 🛠️ Stack Technique & Workflow
L'architecture repose sur trois piliers majeurs :

1. **Extraction & Filtrage (NoSQL)** : Collecte et nettoyage de données massives stockées dans une base de données NoSQL (JSON format).
2. **ETL avec Talend** : 
   - Conception de jobs d'intégration pour transformer les données brutes.
   - Application de filtres complexes et de règles de gestion pour assurer la qualité des données.
3. **Visualisation avec Power BI** :
   - Création de rapports interactifs.
   - Mise en place de KPIs décisionnels pour répondre à des problématiques métier spécifiques.

## 🎯 Objectifs Décisionnels
L'enjeu n'était pas seulement d'afficher des données, mais de permettre de :
* Identifier les tendances clés via des filtres dynamiques.
* Optimiser les processus en isolant les anomalies dans les données collectées.
* Fournir une vision claire pour faciliter les décisions stratégiques.
